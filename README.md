# Ignacio Bolívar Centeno

Physicist with a computational background: scientific Python and simulation codes (DFTB+,
LAMMPS, ADDA).

## Results

- **New linear codes over GF(4).** Thirteen codes whose minimum distance is one or two above the
  lower bounds in Markus Grassl's tables at [codetables.de](https://www.codetables.de), as read
  on 2026-11-05; together they raise 29 cells of the table. They were sent to the table's
  maintainer on 2026-11-05. Generator matrices and constructions are in
  [linear-code-records](https://github.com/IgnacioBolivarCenteno/linear-code-records), archived
  on Zenodo as [10.5281/zenodo.23989998](https://doi.org/10.5281/zenodo.23989998).
- **New lower bounds for binary constant-weight codes.** A(26,10,12) ≥ 213, up from 208, from a code
  built by shortening Echols's (27,10,13) code and a local search; and A(54,6,5) ≥ 2210, up from
  2159, by shortening the code behind A(55,6,5) ≥ 2431. Both were added to Andries Brouwer's
  [table of bounds for constant-weight codes](https://aeb.win.tue.nl/codes/Andw.html) on
  2026-11-09.

These results were found with AI agents (Claude, by Anthropic), which wrote and ran the searches
and the checks under my direction.
